# 时代校验速查表（元代实例）

> 校某代书，替换为该代知识库即可，检查框架不变。数据源：陈垣《校勘学释例》卷三、卷四、卷五、卷六第四十四至四十七。

## 1. 用字层五查

### 1.1 简笔字误读（元作 → 后人误作）

| 元作 | 误作 | 元作 | 误作 |
|---|---|---|---|
| 无（無简笔） | 元 | 著 | 省 |
| 體 | 休 | 舊 | 田 |
| 廳 | 所 | | |

规则：见可疑处先问"是否简笔字之误读"，再谈改字。

### 1.2 误以为简笔回改而误
原文本非简笔，校者误以为是简笔而回改成"正体"——反而制造新误。回改前必须先确认原文确系简笔。

### 1.3 译音用字
译音无定字但有界限（歹、斡、赤、亦木术、拔都…），不得按义理改译音字。
**界限（P10）**：讹成异字且失原形者仍为误——"完泽驾"之"驾"为"笃"之讹，不得委之"译音无定字"。

### 1.4 后起字
后世才造的字（赔、账、僱、毡、袄、灶、晒、碗）不得回改当时写法（钞、帐、雇、氈）。

### 1.5 与今不同
他每=他们；见=现；抄=钞；根随=跟随。是当时用字，非误字。

## 2. 用语层

- 元时语法："每"作复数词尾（官人每=官人们），不得按后代语法处理。
- 当时用语（校者不谙而误改）：勾当/勾补、检勾、根脚、劄送、译该、诸色、好生。
- **判衍前置铁律**：疑某字为衍，先查它与时代用语的关系——吏八三"检勾当人员"（"当"字衍是误判，"检勾"亦用语）、"根底脚浅短"（"底"衍是误判，"根脚"是用语）、刑十九"诸色目人等"（"目"衍是误判，"色目""诸色"皆用语）。

## 3. 语序层（倒置词清单，禁止乙转）

物货、地土、选拣、月日、病患、财钱、刷磨、才方、守把、妻夫、姑舅、户门、弟兄、卖买、去失、位牌、儿男、寸分、识认、背违、秽污、腹肚、分另、存留、右左手、三二十……

规则：
1. 本书一律作某序（如全作"物货"）→ 时代语序，**禁止乙转**。
2. 确系个别错乱（本书他处皆作今序）→ 才可乙正，并注明依据。
3. 况元代语系至繁，语序含翻译成分，"决不应以今语改古语"。

## 4. 名物制度层

### 4.1 年代合法性
- **年号年限**：至大仅四年（"至大五年/八年/二十一年"以上皆误）；至元三十一年（"至元三十三年"当作"二十三年"）；大德十一年（"大德十六年"衍字）；元贞二年（"元贞三年"当作"二年"）。
- **年号混用**：后代/前代年号不应出现——元书"正统五年"（明年号）当作"中统"；"元祐六年"（宋年号）当作"延祐"。
- **合称拆衍**："至大德"= 至大+大德粘连，其中一字衍。
- **属相纪年**（蒙古俗）：以鼠牛等十二属纪年；"猪儿年"误"猪鼠年"、"马儿年"妄加"于至元"皆误。
- **闰月**：某年无闰而文有闰月则误（延祐七年无闰，"闰三月"元作"元年"）。

### 4.2 帝号庙号
- 元太祖"圣武"误"神武"；元无"圣祖"（误"世祖"）；世祖不称"高皇帝"（清人习闻清制妄加）。
- 国语帝号译音：完者都/完者笃/完泽笃皆元成宗。

### 4.3 部族名
蒙古称"达达"不单称"达"；三分：蒙古、色目（恒误"色日"）、汉人；色目含唐兀（误"唐元"）、阿速（误"呵速"）、木速鲁蛮（误"本速鲁蛮"）、也里可温、回回；女真亦称汉人（误"女贞"）。

### 4.4 地名五级诊断（由易到难）
1. **历代所无** → 一望即知误（平湾→平滦、箪州→单州、普晋路→晋宁路）。
2. **该代所无（后世才有）** → 略考即知误（广东行省→湖广行省、重庆府→重庆路）。
3. **该代所有而隶属不相应** → 易察觉（景州溧阳→滦阳，两地不相接；威宁→咸宁，属鄂州路）。
4. **该代所有而未指明隶属** → 非对校莫知其误（濮州→滁州、郭州→漷州）。
5. **地名误作非地名** → 非对校莫知（"李二等"实为"李二寺"；"上有攸县"实为"上犹攸县"）。

前三级凭政区知识，后两级必须对校。**必须用所校朝代的政区资料**。

### 4.5 人名（译音）
常见正形：帖木儿、囊家歹（误"土豪家歹"）、阿合马（漏"合"/倒"合阿马"）、阔阔、阿术、相威、安童、拜住（误"拜征"）；回回人名常以"丁"结尾（忽都不丁误"忽都不下"）；"火者"为常名。名从主人 + 译音界限。

### 4.6 官名（防"以清改元"）
- 典吏 → 误改"典史"（元制两有，校者习闻典史，两页内三十三处均误改）。
- 提点/提领 → 误改"提调"（清制习语）。
- 总把（元官）→ 误改"把总"（清官名）。
- 达鲁花赤（长官）≠ 扎鲁忽赤（断事官），职责不同不容相混。
- 其他：大司农司误"大同农司"、奉礼郎误"奉祀郎"、司晨郎误"司农郎"、万户府误"方户府"。

### 4.7 物名·专名·体制
- **物名**：鞓带（误"鞋带"）、雁翎刀（误"鹰翎刀"）、兔鹘（误"鹃"）、胖袄（误"畔袄"）。规则：不能以后世不经见谓前代为无，不能以后世习见疑前代亦有。
- **专名**：腹里（误"肠里"）、券军（误"募军"）、投拜户、铺马（误"補马"）、倒钞（误"例钞"）、朱销文簿、舍里别（煎造之饮，非佛家舍利）。
- **体制**：
  - 怯薛宿卫三日一更："第一日/第二日/第三日"，"第二日"误"第二者"。
  - 圣旨称"钦此"，皇太后懿旨/太子令旨称"敬此"——不得互用。
  - 禁刑日：每月朔望二弦（初一/初八/十五/二十三），误"初二/二十五"。
  - 笞杖以七为度：始七止百七；称"下"者必为单数之七（笞五十七下）——"既言下必言七，不言七者非脱七即衍下"。
  - 圆坐署事/圆议/圆押（类圆桌会议），"圆"多误"图/原/元"。
  - 口供称"招伏/状招"，无"招状/状伏"之称。
  - 墨钉（墨方）：开雕时庙号未颁留墨方，后人只可注"当是某字"，**不得径填**。

## 5. 不校边界专用字清单

### 5.1 通用字组（两形并用，不强行统一）
教/交、札/劄、呈/承、整/拯、您/恁、驱/躯、疋/匹、只/止、後/后、卓/棹、殴/欧、礙/碍、杖/仗、应付/应副、驸马/附马、守制/守志。

### 5.2 底本专用字（虽与他字通用，本书只用其一，不得以通用字改易）
- "闲"专用：嫺习、閒暇义均用"闲"（沈刻多改"閒"）。
- "攀"专用：扳援义均用"攀"（攀连/指攀/妄攀）。
- 搔扰（骚必用"搔"）；疎放（疏必用"疎"）；赀财（资作"赀"）；价直（值作"直"）；婿（必用"婿"）；杨州（扬作"杨"）；城廓（郭作"廓"）；木绵（棉作"绵"）。

规则：即便以通用字改之"于义无殊"甚至"更优"，也不得改——掩本来面目，为研究时代文字者增一重障碍。整理时著例"某字本书一律作 X，今仍之"。

## 6. 版本源流提示

### 6.1 年月增入异源（卷六第四十九）
后代刻本某段区域性集中增入年月日而他本所无 → 疑别有所本。判定：记录起止范围与规律 → 与目录、本条下文比对（增入与下文矛盾者标存疑，如"至元二十四年二月日"九字他本无而下文与目录均作二十三年）→ 输出假设，不武断，不改字，待新材料。

### 6.2 关键单字影响评估（卷六第五十）
一字可定全书："板行"（地方官吏自行刻板）vs"颁行"（中央颁布）决定《元典章》是地方编纂还是中央颁行；"至治二年/三年"一字之误牵动全书编纂下限。处理：以证据链支撑，涉及版本源流宁存疑著录，不径改。
